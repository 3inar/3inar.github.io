## Importing some libraries
```scheme
(import (chicken string) (chicken condition))
```

All scheme modules + `(chicken base)` are imported by default.

## Strings
### In `(chicken string)`
```scheme
(string-split "hello w" " ") ==> ("hello" "w")
```

## I/O
### Read all the lines in a file
The `read-lines` function is in `(chicken io)`

```scheme
(with-input-from-file "myfile.txt" read-lines)
("firstline" "nextline" "nextline" "nextline")
```

## What is a thunk?
It's a function that takes no argument and does a little thing. It's used for
lazy evaluation apparently. 

See 
[this stackoverflow A](https://stackoverflow.com/questions/925365/what-is-a-thunk-as-used-in-scheme-or-in-general):

```scheme
#;11> (define foo (+ 2 3))
#;12> foo
5
#;13> (define foo (lambda () (+ 2 3)))
#;14> foo
#<procedure (foo)>
#;15> (foo)
5
```


## Define a struct
It's in `(chicken base)`. They call it a record:

```scheme
(define-record point x y)
(define p1 (make-point 123 456))
(point? p1)                      ==> #t
(point-x p1)                     ==> 123
(point-y-set! p1 99)
(point-y p1)                     ==> 99
```
