CHICKEN scheme quick reference

How to do things. For a homebrew install on mac there are docs in . your version number may vary.

Importing some libraries

(import (chicken string) (chicken condition))

All scheme modules + (chicken base) are imported by default.

Strings

In (chicken string)

(string-split "hello w" " ") ==> ("hello" "w")

Define a struct

It’s in (chicken base). They call it a record:

(define-record point x y)
(define p1 (make-point 123 456))
(point? p1)                      ==> #t
(point-x p1)                     ==> 123
(point-y-set! p1 99)
(point-y p1)                     ==> 99
